# Coding Readability Optimiser

When doing research, it is important to ensure research integrity. To put it simply, can you understand the analysis that is being done and can you conclusively determine whether the research is done correctly? Do you know enough of what the research is for you to be accountable for the research outcomes? For me, I think the easiest way to ensure this is to ensure that code is still readable. That means that while it is expected that the user knows how to code, the AI should be able to adopt their style of coding, similar to how each of us has a style of writing. Is there a way we can teach agents to adopt our coding style to write code that we understand and we could feasibly understand, and thereby critically assess? That is the basic question behind this repository?

Do I think it is possible? I don't know. Why? Because I think that AI still has a fundamental fingerprint that make its output unique compared to humans. If this occurs in writing pieces such as stories, then I presume the same translates to code. However, I would like to be proven wrong. If I am proven wrong, then there is a systematic way to teach an agent how you code, what your coding preferences, and thereby how to write all code in the future. This makes such a repository very useful for any researcher trying to do any form of agentic-driven research with integrity, because no matter how capable agents are, they will always misinterpret goals, hallcuinate solutions, unintentionally fabricate results, etc.

We can only be sure of the output generated by agents in research if - 
1. We have sufficient experience within the field (even then that is risky)
2. We find ways to make the ouptut generated by agents intelligible, readable and grounded in truth.

I think we have successfully made agents grounded in truth, yet outside of specific industry-driven contexts, we haven't made their output (especially code output) particular readable.

The solution may seem simple - fine tune an existing agentic coding model. Problem with that is - no one wants to do that. Everyone wants something that just plugs straight in with Codex or Claude Code and just works. Is there a way to pull that off?
